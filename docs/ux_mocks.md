# UI & UX Mockups - Country Dairy

This document showcases the visual design guidelines, wireframe elements, and user experience layout drafts for both the customer e-commerce web app and mobile application.

---

## 1. Brand Identity & Visual Language
*   **Aesthetic Theme**: Premium Farm-fresh Organic, clean, minimalist, high contrast.
*   **Color Palette**:
    *   `Primary (Forest Green)`: `#3A6038` — represents organic nature, grass, fresh cows.
    *   `Accent (Soft Gold)`: `#C59B27` — represents pure A2 ghee, lab quality stamp.
    *   `Background (Warm Cream)`: `#FAF8F3` — clean organic canvas, avoiding harsh digital white.
    *   `Secondary Text (Dark Charcoal)`: `#2A2A2A` — sharp legibility.
*   **Typography**: Serif headers (e.g., *Playfair Display* or *Outfit*) for a premium, heritage feel, paired with geometric sans-serif (e.g., *Inter* or *Roboto*) for app UI labels.

## 3. Customer Mobile App Product Detail View (iOS/Android Mockup)

The mobile detail page emphasizes quick checkout vs subscription configuration and clear batch purity parameters.

![Product Detail Page](file:///Users/deepakchand/workspaces/country_dairy/docs/images/mobile_app_product_detail.png)

### Key Page Elements:
1.  **Product Carousel**: Crisp glass container images showing A2 cow milk texture.
2.  **Purity Badge**: "Lab Test Certified | Purity Verified 100%" displaying transparent laboratory records link.
3.  **Checkout Option Toggle**:
    *   `Buy Once | ₹95`: Standard checkout.
    *   `Subscribe & Save | ₹85`: Unlocks daily calendar layout setup.
4.  **Quantity Adjuster**: Dynamic step increment (`- 1 +`).
5.  **Sticky Bottom Action Bar**: "Add to Cart" CTA with total pricing estimation.
